# Утилита файловой системы

Приложение написано на Python с графическим интерфейсом Tkinter и предназначено для работы в Windows.

## Возможности

- Поиск и удаление выбранных пустых папок с учётом вложенных каталогов и пользовательских исключений.
- Поиск в отдельном потоке с индикатором, счётчиком проверенных папок и возможностью отмены.
- Создание файлов заданного размера с нулями или случайными данными, отображением прогресса и возможностью отмены.
- Проверка введённых данных и запись операций, удалённых путей и ошибок в `operations.log`.

## Запуск

Установите Python 3 с поддержкой Tkinter и выполните из папки проекта:

```powershell
python main.py
```

Также можно запустить `main.py` в PyCharm. Дополнительные сторонние библиотеки не требуются.

## Удаление папок

По умолчанию из поиска исключаются Windows, Windows.old, Program Files, Program Files (x86), ProgramData и AppData пользовательских профилей. Их можно включить галочкой «Включить системные папки»; перед удалением защищённых папок появится дополнительное предупреждение.

Папки удаляются без перемещения в корзину. Даже пустая папка может быть нужна программе, поэтому защита не гарантирует безопасность удаления всех результатов поиска. Рекомендуется проверять выбранные пути и очищать каталоги, назначение которых известно.

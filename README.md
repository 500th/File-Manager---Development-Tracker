# File Manager Utility

**File Manager Utility** — настольная программа для Windows, которая помогает находить и удалять пустые каталоги и создавать тестовые файлы. Интерфейс разработан на Python с использованием Tkinter.

## Возможности

- Поиск пустых папок с учётом вложенности, исключений и защиты системных каталогов.
- Просмотр результатов, выбор каталогов и удаление после подтверждения.
- Создание файлов заданного размера (КБ, МБ, ГБ) с нулевыми или случайными данными.
- Проверка параметров, отображение прогресса, отмена операций и журналирование ошибок.

## Скачать и запустить

1. Откройте раздел **[Releases](../../releases)** и скачайте `File_Manager_Utility.exe` из последнего релиза.
2. Запустите скачанный файл на Windows.

**Устанавливать Python не нужно.**

## Важно

Удалённые папки **не перемещаются в корзину**, а отмена операции не восстанавливает уже удалённые каталоги. Перед удалением внимательно проверяйте выбранные пути. Для первого запуска используйте тестовые папки.

## Журнал операций

Журнал сохраняется между запусками приложения в файле:

```text
%LOCALAPPDATA%\File_Manager_Utility\operations.log
```

Открыть папку можно через **Win + R**, введя `%LOCALAPPDATA%\File_Manager_Utility`.

## Запуск из исходного кода

Потребуется Python 3 с поддержкой Tkinter. В корне проекта выполните:

```powershell
python main.py
```

## Сборка EXE

Для самостоятельной сборки на Windows:

```powershell
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --clean --noconfirm --name File_Manager_Utility main.py
```

Готовый файл появится в `dist/File_Manager_Utility.exe`.
